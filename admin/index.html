Welcome back

Pick a section on the left. Changes are kept in this tab until you press Save, which writes the JSON file into your folder.

  • Lists of things (projects, photos, steps) can be added, reordered, duplicated or removed.
  • Images: use Upload next to any image field — the file is copied into your folder and the path is filled in.
  • Live numbers: write {years} or {tenure} in text, or {auto} as a timeline duration.
  • Adding an achievement, personal project or new role offers to post it to What's New too.
  • Promoted? Quick add → + New role / promotion ends your current role and makes the new one current everywhere on the site.
  • Certificates (Home) switch to Expired by themselves after their "valid until" date.
  • To publish: commit and push the folder (e.g. GitHub Desktop or git add -A && git commit -m "Update content" && git push).

Add this to What's New?

It will appear at the top of the What's New page and as the "New" link on your homepage.
